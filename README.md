# FinSmart

Android-приложение для учёта и анализа расходов по банковским CSV-выпискам. MVP объединяет категоризацию операций, финансовые цели, каталог скидок одного магазина и одну объяснимую ИИ-рекомендацию. Приложение должно показывать ранее загруженные данные без сети.

Банковские API, хранение банковских логинов, платежи и банковский кешбэк в MVP не входят.

## Состав MVP

- Android-клиент на Kotlin с Room, локальным кэшем и очередью изменений.
- Backend на Kotlin + Ktor с PostgreSQL; сервер — источник истины.
- Импорт CSV, категоризация по MCC и аналитика только расходов.
- Финансовые цели и предложения одного магазина, отбираемые по категориям.
- ИИ формулирует одну рекомендацию на основе серверных агрегатов; финансовые расчёты выполняются обычным кодом.

## Запуск backend

Нужны Docker Desktop и (для разработки в IDE) JDK 21.

```bash
docker compose up --build
```

Поднимаются PostgreSQL 16 и API на `http://localhost:8080`. При старте API применяет Flyway-миграции и справочники категорий/MCC.

Проверка: `http://localhost:8080/health` → `{"status":"ok","database":"ok"}`.

Порты и пароль БД можно поменять в `.env` (шаблон — `.env.example`). Полный сброс БД: `docker compose down -v`.

Если порт 8080 занят (например, локальным веб-сервером), задайте `API_PORT` в `.env`. Для общих окружений обязательно задайте свой `JWT_SECRET` (32+ символа). Сквозная проверка демо-сценария: `bash scripts/smoke.sh` (см. `docs/operations/backend-handoff.md`).
