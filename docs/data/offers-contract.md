# Контракт каталога скидок

Этот документ описывает структуру тестового каталога скидок FinSmart.

Файл с предложениями находится по адресу:

`fixtures/offers/offers.json`

Корневой элемент файла — JSON-массив. Каждый элемент массива представляет одно предложение.

## Поля предложения

| Поле | Тип | Описание |
|---|---|---|
| `sourceId` | string | Уникальный идентификатор предложения |
| `title` | string | Название товара или предложения |
| `category` | string | Категория FinSmart |
| `regularPrice` | number или null | Обычная цена |
| `salePrice` | number или null | Цена по акции |
| `currency` | string | Валюта, для MVP используется `RUB` |
| `validFrom` | string или null | Дата начала действия в формате `YYYY-MM-DD` |
| `validTo` | string или null | Дата окончания действия в формате `YYYY-MM-DD` |
| `conditions` | string или null | Дополнительные условия акции |
| `url` | string | Ссылка на источник |
| `region` | string или null | Регион действия предложения |
| `checkedAt` | string | Время проверки источника в формате ISO 8601 |

## Категории

Допустимые категории:

- `groceries` — продукты;
- `cafes` — кафе и готовая еда;
- `transport` — транспорт;
- `health` — здоровье;
- `home` — дом;
- `entertainment` — развлечения;
- `other` — прочее.

## Правила загрузки

1. Предложения загружаются по уникальному полю `sourceId`.
2. Повторная загрузка обновляет существующую запись и не создаёт дубль.
3. Неизвестные цены, даты, условия или регион записываются как `null`.
4. Пустой или некорректный файл не должен удалять предыдущий каталог.
5. Если `validTo` указано и эта дата уже прошла, предложение не возвращается в обычном списке. Если `validTo` равно `null`, предложение не считается просроченным.
6. Тестовые предложения помечаются префиксом `[ДЕМО]`.

## Расчёт потенциальной выгоды

Потенциальная выгода рассчитывается только тогда, когда известны обе цены:

`regularPrice - salePrice`

Расчёт выполняется только при условии:

`regularPrice != null`

`salePrice != null`

`salePrice < regularPrice`

Потенциальная выгода является справочной. Она не считается деньгами, которые пользователь уже сэкономил.
