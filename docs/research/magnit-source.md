# Источник скидок «Магнита»

Дата исследования: 29.10.2026.

## Решение для MVP

Для демонстрационной версии FinSmart используется тестовый каталог:

`fixtures/offers/offers.json`

Предложения в этом файле являются вымышленными и не считаются действующими акциями «Магнита». Все названия помечены префиксом `[ДЕМО]`.

Настоящий автоматический парсер сайта в текущий MVP не входит.

## Возможный источник

Официальный сайт:

https://magnit.ru/

Файл robots.txt:

https://magnit.ru/robots.txt

Выбранный регион для демонстрации:

Екатеринбург.

На сайте отображаются товары и предложения, но команда пока не подтвердила наличие открытого официального API для получения каталога скидок.

Цены и наличие товаров могут зависеть от выбранного города и конкретного магазина.

## Ограничения автоматического получения

Перед созданием автоматического загрузчика необходимо:

1. Проверить условия использования сайта.
2. Получить разрешение или найти официальный API.
3. Определить конкретные страницы и регион.
4. Согласовать частоту запросов.
5. Не обходить авторизацию, ограничения доступа и защиту сайта.

В robots.txt запрещён автоматический обход некоторых внутренних и параметризованных страниц. Поэтому в MVP такие страницы автоматически не загружаются.

## Частота обновления

Предварительный вариант после получения разрешения — обновление не чаще одного раза в 24 часа.

Эта частота пока не является окончательной и должна быть согласована с источником и тимлидом.

## Возможные способы получения данных в будущем

1. Официальный API «Магнита».
2. Разрешённый JSON или CSV-файл.
3. Ручное обновление тестового каталога.
4. Ограниченный парсер публичных страниц после проверки разрешений.

## Поведение при ошибке

Ошибка источника не должна удалять последний успешно загруженный каталог.

Пустой или повреждённый файл не должен заменять сохранённые предложения.

## Скидка и кешбэк

В каталоге FinSmart хранятся скидки магазина.

Банковский кешбэк, бонусы и партнёрские финансовые предложения являются другими видами выгоды и не должны записываться как обычные скидки на товары.
