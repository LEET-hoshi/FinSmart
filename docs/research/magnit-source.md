# Источник скидок «Магнита»

Дата первоначального исследования: 29.10.2026.
Дата последней проверки: 06.11.2026.

## Источник данных

Для получения предложений используется публичная страница официального сайта сети «Магнит»:

https://magnit.ru/promo-catalog

Выбранный регион:

Екатеринбург, Свердловская область.

Цены, наличие товаров и состав предложений могут зависеть от региона и конкретного магазина. В ссылках полученных карточек используется код магазина `shopCode=992301`.

## Тестовый каталог

Для разработки и демонстрации без доступа к сайту сохраняется тестовый каталог:

`fixtures/offers/offers.json`

Предложения в тестовом каталоге являются вымышленными. Они помечены префиксом `[ДЕМО]` и полем:

`isTest: true`

Тестовый каталог не должен восприниматься как список действующих акций «Магнита».

## Автоматический adapter

Для экспериментального получения данных создан adapter:

`scripts/update-magnit-offers.mjs`

Правило получения данных API Anything находится в файле:

`tools/api-anything/sites/magnit-ru.json`

Adapter получает с публичной страницы следующие данные:

- название предложения;
- ссылку на источник;
- акционную цену, если она показана;
- обычную цену, если она показана;
- размер скидки, если он показан.

Данные преобразуются в контракт FinSmart:

- `sourceId` формируется из идентификатора товара в ссылке;
- цены приводятся к строке с двумя знаками после точки;
- неизвестные цены и даты записываются как `null`;
- валюта записывается как `RUB`;
- для полученных с сайта записей используется `isTest: false`;
- время проверки записывается в `checkedAt`.

Если на карточке товара нет цены, adapter не придумывает её и сохраняет `null`.

## Запуск adapter

Обычный запуск:

```bash
node scripts/update-magnit-offers.mjs
```

Принудительное обновление для ручной проверки:

```bash
node scripts/update-magnit-offers.mjs --force
```

Полученный каталог сохраняется локально:

`build/generated/fixtures/offers/offers.json`

Папка `build` не добавляется в Git.

Для запуска backend с полученным каталогом используется команда:

```bash
FIXTURES_DIR="$PWD/build/generated/fixtures" DB_PORT=55432 docker compose up --build -d
```

## Ограничение частоты

Без параметра `--force` источник проверяется не чаще одного раза в 24 часа.

Параметр `--force` предназначен только для ручной проверки и не должен использоваться для постоянного частого опроса сайта.

## Timeout и User-Agent

На получение данных установлен timeout 30 секунд.

Если источник не отвечает за это время, выполнение прекращается с ошибкой.

HTTP-запрос содержит `User-Agent`, сохранённый в правиле API Anything.

## Поведение при ошибке

При ошибке источника предыдущий успешно созданный каталог не удаляется.

Новый каталог сначала записывается во временный файл. Основной файл заменяется только после успешного получения и преобразования непустого списка предложений.

Пустой или некорректный ответ источника не должен заменять предыдущий каталог.

Backend загружает предложения с upsert по `sourceId`. Повторная загрузка обновляет существующие записи и не создаёт дубли.

## Логирование

В журнал записываются:

- начало обновления;
- количество полученных предложений;
- количество сохранённых предложений;
- описание ошибки без содержимого cookies, токенов и персональных данных.

Персональные данные пользователей в запросах и журналах не используются.

## Проверка

Во время локальной проверки:

- с публичной страницы получено 30 предложений;
- в формат FinSmart преобразовано 30 предложений;
- некорректные записи отсутствовали;
- backend загрузил 30 предложений;
- повторный запуск оставил 30 записей с `sourceId`, начинающимся на `magnit-`;
- дубли при повторной загрузке не появились.

## Ограничения и условия использования

Перед использованием adapter вне учебной демонстрации необходимо:

1. Повторно проверить актуальный `robots.txt`.
2. Проверить условия использования сайта.
3. Согласовать автоматическое получение данных с владельцем источника и тимлидом.
4. По возможности использовать официальный API или разрешённый файл данных.
5. Не обходить авторизацию, ограничения доступа и защиту сайта.
6. Не увеличивать частоту запросов без согласования.

Adapter работает только с публичной страницей каталога. Он не выполняет авторизацию и не обходит защиту сайта.

Полученные цены нельзя считать гарантированными: перед покупкой пользователь должен проверить цену и условия акции на официальной странице или в магазине.
