# Источник скидок «Магнита»

Дата первоначального исследования: 29.10.2026.
Дата последней проверки: 13.11.2026.

## Магазин и источник цен

Для учебной демонстрации выбран один магазин: **Екатеринбург, ул. Первомайская, 76**, код `667052`.
Адрес и код проверены через выбор магазина на официальном сайте:

https://magnit.ru/promo-catalog?shopCode=667052&shopType=1

Цены и наличие относятся к этому магазину, а не ко всем магазинам города.

Прежний способ скачивал HTML общей страницы `/promo-catalog`. Она возвращала
рекламные акции без цен и магазин по умолчанию в Краснодаре (`992301`).
Один параметр `shopCode` в адресе HTML не обеспечивал выбор магазина при
таком скачивании. Поэтому подписывать эти данные Екатеринбургом было неверно.

Теперь используется публичный JSON-запрос самого сайта:

```text
GET https://magnit.ru/webgate/v1/promotions/type?storeCode=667052&type=1&limit=30&offset=0&adult=true
```

Путь, параметр `storeCode`, тип товарных акций `type=1` и единицы цены
проверены по JavaScript официального сайта. Запрос проверен без авторизации,
cookies, токенов и личных данных. Это внутренний интерфейс сайта, а не
обещание стабильного публичного API.

Правило запроса находится в `tools/api-anything/sites/magnit-ru.json`.
Сайт требует заголовок `X-App-Version`; при проверке работало значение
`2026.11.11-17.40`. При изменении интерфейса может понадобиться обновление
правила. В запросе указан User-Agent `FinSmart-Educational-Offers-Adapter/1.0`.

## Преобразование данных

Скрипт: `scripts/update-magnit-offers.mjs`.

- `name` становится `title`.
- `id` становится `sourceId` вида `magnit-2190451`.
- Ссылка создаётся из `id` и `slug`, с `shopCode=667052`.
- `price` и `oldPrice` приходят целыми числами в **копейках**:
  `9999` → `"99.99"`, `15999` → `"159.99"`.
- `price` становится `salePrice`, `oldPrice` — `regularPrice`.
  Отсутствующая обычная цена остаётся `null`.
- Записи без корректной текущей цены пропускаются. Цены из рекламного текста
  и цены от покупки нескольких штук не подставляются вместо отсутствующей цены.
- `startDate` и `endDate` сохраняются как `validFrom` и `validTo`.
  Некорректные даты и обратный диапазон отбрасываются.
- Описание акции, отметка скидки и адрес магазина сохраняются в `conditions`.
  Это важно для условий карты «Магнит Плюс» и покупки нескольких товаров.
- `region` — `Екатеринбург`, `currency` — `RUB`, `isTest` — `false`.
- `checkedAt` содержит время получения данных; повторные ID не создают дубли.

Если источник сообщает цену при покупке двух товаров, она остаётся условной:
соответствующее описание сохраняется целиком. Потенциальная разница цен
не является уже полученной экономией пользователя.

## Объём каталога

За один запуск выполняется один запрос: первые **до 30** предложений типа
`1` выбранного магазина. Полная пагинация и все типы акций не реализованы.
Это небольшой каталог для демонстрации, а не все скидки «Магнита».

При проверке 13.11.2026 источник вернул 28 записей. У 23 была числовая
текущая цена; они сохранены. Пять записей без неё пропущены.
Это наблюдение конкретного запуска: количество и цены могут меняться.

## Запуск

Нужен Node.js 22.13 или новее. В корне проекта:

```bash
npm ci
npm test
node scripts/update-magnit-offers.mjs
```

Для отдельной ручной проверки обновления:

```bash
node scripts/update-magnit-offers.mjs --force
```

Скрипт вызывает локально установленный API Anything через Node.js.
Рабочий запуск не использует `npx -y` и не зависит от `npx.cmd` в Windows.

Результат:

```text
build/generated/fixtures/offers/offers.json
```

Папка `build` не добавляется в Git. Для запуска backend с этим каталогом
в macOS/Linux:

```bash
FIXTURES_DIR="$PWD/build/generated/fixtures" DB_PORT=55432 docker compose up --build -d
```

В PowerShell:

```powershell
$env:FIXTURES_DIR = "$((Get-Location).Path)/build/generated/fixtures"
$env:DB_PORT = "55432"
docker compose up --build -d
```

Backend использует upsert по `sourceId`; истёкшие предложения исключает
из обычного списка. Запуск адаптера сам по себе не перезапускает backend.

## Ошибки, кэш и ограничения запросов

Без `--force` свежий каталог используется 24 часа. Файл без цен,
некорректный JSON и файл другого магазина не считаются пригодным кэшем.

Вызов CLI ограничен оставшимся временем общего лимита 30 секунд.
Перед записью лимит проверяется повторно. Файл сначала записывается
во временный, затем атомарно заменяет предыдущий каталог.

При ошибке сети, timeout, повреждённом или пустом ответе, а также отсутствии
корректных товаров с ценой обновление завершается с ошибкой. Предыдущий файл
остаётся на месте. Число полученных, сохранённых и пропущенных записей
выводится в журнал вместе с адресом магазина; секреты не журналируются.

`--force` предназначен для редкой ручной проверки, а не частого опроса.

## Проверки

`npm test` запускает семь тестов без сети:

1. Перевод копеек в рубли и обработка отсутствующих/неправильных цен.
2. Запрос выбранного магазина и товарного типа акций.
3. Контракт, условия карты/количества, даты и уникальные ID.
4. Пропуск предложений без цены, без догадок по описанию.
5. Сохранение предыдущего каталога при ошибках и timeout.
6. Отбрасывание кэша без цен или с другим магазином.
7. Запуск CLI через Node.js и отсутствие дублей при повторной записи.

`fixtures/offers/magnit-source-sample.json` — сокращённый снимок двух
ответов для тестов, не обновляемый действующий каталог.

Ручной запуск 13.11.2026: получено 28, сохранено 23, пропущено 5.
Например, для сыра «Ламбер» получены 99,99 ₽ и обычная цена 159,99 ₽;
условие карты и даты 11–17 ноября сохранены. Подтверждены цены в локальном
JSON. Эта проверка сама по себе не подтверждает отображение в Android.

## Демонстрационные данные и дальнейшее использование

В `fixtures/offers/offers.json` остаётся отдельный вымышленный каталог
для работы без сайта: названия с `[ДЕМО]` и `isTest: true`.
Он не заменяется живой выгрузкой и не выдаётся за действующие акции.

Перед использованием вне учебной демонстрации необходимо проверить
актуальные условия сайта и `robots.txt`, согласовать автоматическое
получение и частоту запросов с владельцем источника и тимлидом.
Adapter не обходит авторизацию и защиту. При отказе источника сохраняется
прошлый каталог; гарантировать неизменность внешнего интерфейса нельзя.

Перед покупкой следует проверять цену, наличие и условия на официальной
странице или в выбранном магазине.
