# Примеры ответов каталога скидок для Android

Примеры показывают формат ответов backend. Названия и значения являются демонстрационными и не считаются действующими акциями.

Для запросов требуется заголовок авторизации:

`Authorization: Bearer <accessToken>`

## Предложение без региона

Запрос:

`GET /offers?region=Екатеринбург`

Предложение с `region: null` считается доступным во всех регионах и должно отображаться Android-приложением.

Ответ `200 OK`:

```json
{
  "items": [
    {
      "id": "11111111-1111-4111-8111-111111111111",
      "sourceId": "example-magnit-no-region",
      "title": "[ПРИМЕР] Товар без ограничения по региону",
      "category": "groceries",
      "regularPrice": "149.99",
      "salePrice": "109.99",
      "currency": "RUB",
      "validFrom": null,
      "validTo": null,
      "conditions": null,
      "url": "https://magnit.ru/promo-catalog",
      "region": null,
      "checkedAt": "2026-11-06T20:37:16Z",
      "potentialSaving": "40.00"
    }
  ],
  "catalogCheckedAt": "2026-11-06T20:37:16Z"
}
```

## Предложение без обычной цены

Если `regularPrice` отсутствует, потенциальная выгода не рассчитывается.

Ответ `200 OK`:

```json
{
  "items": [
    {
      "id": "22222222-2222-4222-8222-222222222222",
      "sourceId": "example-magnit-no-regular-price",
      "title": "[ПРИМЕР] Товар без обычной цены",
      "category": "groceries",
      "regularPrice": null,
      "salePrice": "64.99",
      "currency": "RUB",
      "validFrom": null,
      "validTo": null,
      "conditions": "Цена показана на странице акции",
      "url": "https://magnit.ru/promo-catalog",
      "region": "Екатеринбург",
      "checkedAt": "2026-11-06T20:37:16Z",
      "potentialSaving": null
    }
  ],
  "catalogCheckedAt": "2026-11-06T20:37:16Z"
}
```

Android не должен показывать сумму выгоды, если `potentialSaving` равно `null`.

## Просроченное предложение

Предложение с `validTo` раньше текущей даты не включается в `GET /offers`.

Если Android запрашивает карточку просроченного предложения:

`GET /offers/33333333-3333-4333-8333-333333333333`

Backend возвращает `404 Not Found`:

```json
{
  "code": "not_found",
  "message": "Объект не найден",
  "details": null
}
```

Android должен закрыть недоступную карточку или показать сообщение, что предложение больше не действует.

## Пустой список

Пустой список является успешным ответом, а не ошибкой.

Ответ `200 OK`:

```json
{
  "items": [],
  "catalogCheckedAt": "2026-11-06T20:37:16Z"
}
```

Android должен показать пустое состояние, например:

`Подходящих предложений пока нет`

Не нужно показывать сообщение об ошибке сети.

## Каталог ещё не загружался

Если успешной загрузки каталога ещё не было:

```json
{
  "items": [],
  "catalogCheckedAt": null
}
```

Android может показать сообщение:

`Каталог пока не загружен`

## Основные правила для Android

1. `items: []` — успешный пустой результат.
2. `region: null` — предложение действует для любого региона.
3. `regularPrice: null` — обычная цена неизвестна.
4. `potentialSaving: null` — сумму выгоды показывать нельзя.
5. Ответ `404` для карточки — предложение отсутствует или уже просрочено.
6. Поля цен передаются строками, чтобы не терять точность.
